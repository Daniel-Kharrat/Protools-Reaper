Did you save your own configuration file?

Import your saved configuration

  1. Open the import dialog In REAPER go to Options → Preferences, and under General settings click Import configuration...
  2. Choose your file Find the configuration file you saved earlier, then click Open and Import.

This replaces your current configuration with the one in your file.

What are you restoring from?

Get your own configuration back

  1. Run the restore script Open the actions list and run
    Daniel_Restore config before Daniel Kharrat.lua
    This restores the configuration you had before installing mine.

Go back to the version before the update

  1. Run the restore script Open the actions list and run
    Daniel_Restore personal settings.lua
    This brings back the version of my configuration you had before the update.

Is this a brand-new REAPER installation?

Install the configuration

  1. Install ReaPack Download it from reapack.com
    In REAPER go to Options → Show REAPER resource path in Explorer/finder...
    Look for a folder called UserPlugins and put the ReaPack file in it
    Restart REAPER
  2. Import the configuration Download the latest configuration
    In REAPER go to Options → Preferences
    Under General settings click Import configuration...
    Find the file you just downloaded, click Open then Import
  3. Synchronize packages Go to Extensions → ReaPack → Synchronize packages
    It will install Daniel Kharrat and ReaTeam Extensions
    After both repositories finish installing, restart REAPER
  4. Open the actions list and run these two scripts
    Daniel_Set splash screen.lua
    Daniel_Replace toolbar_icons.lua

Do you have ReaPack installed?

Update your configuration

  1. Update the scripts only In REAPER go to Extensions → ReaPack → Synchronize packages
  2. Get the newest configuration Open the actions list and run
    Daniel_Update configuration.lua
  3. If you reinstalled REAPER and the toolbar icons turned green Open the actions list and run
    Daniel_Replace toolbar_icons.lua
    to bring back my blue icons.

🍎 Small tweak for macOS 🍎

The configuration uses cmd + space to record, which clashes with Spotlight Search on macOS.
Go to System Settings... → Keyboard → Keyboard Shortcuts... → Spotlight and change:

  • Show Spotlight search to opt + space
  • Show Finder search window to opt + cmd + space
Works on
macOS Windows Linux
